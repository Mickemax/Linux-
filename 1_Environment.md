# Four Different part of a Linux System
    # Linux Kernel
        Interface between software and the computer hardware on the computer sytem.

    # GNU Utilities
        Provide Command-line Program for managing files and programs created by "GNU's not UNIX" Project

    # User Interface
        Provide a way to communicate with the Operating System, either through GUI or CLI.

    # Application Software
        Provides desktop and server programs for diverse things as editing and serving web pages.
