- A module is a self-contained driver library file. The advantage of using modules, instead of compiling all their features into the kernel,is that they keep the Linux kernel lighter and more agile.

# Exploring Kernel Modules
    - Kernel modules come in differnt flavors. They are as follows:
        - Device driver: Facilitates communication with a hardware device.
        - Filesystem driver: Required for filesystem I/O.
        - Network driver: Used to implement network protocols.
        - System calls: Provides additional functions for adding/modifying system services.
        - Executable loader: Allows additional executable formats to load.
    - Modules required to support a kernel are stored in the /lib/modules/ directory tree. Each Linux kernel version available on your system has its own subdirectory within the /lib/modules/ directory.
    - Be aware that distributions may implement this directory a little differently. 
    - You can customize a module to define any unique parameters required, such as hardware settings essential for te device to operate.
        * /etc/modprobe.d/ or /etc/modules-load.d/ contains configuration files generated at system installation or created by an administrator.
        * /lib/modprobe.d/ stores configuration files generated by third-party software packages.
        * /usr/lib/modprobe.d/, if it exists is typically hard-linked to he /lib.modprobe.d/ directory.
        * /run/modprobe.d/ stores configuration files generated at runtime.
     - Many device driver kernel modules are loaded either at system boot time or dynamically whe hardware devices are attached to the system. If problems occur, you need to know what utilities to use to help you diagnose the issue. There are three handy programs tha can help with modules:
        * dmesg displays the current kernel ring buffer. It is will simply dump the currrent kernel ring buffer to STDOUT.
        * lsmod shows brief module information. It display the status of modules currently within the Linux kernel.
        * modinfo provides detailed module data. You can find out more detailed information concerning a particular kernel modue via the modinfo. It may require SU privileges.
    - A ring buffer is a fixed-size data structure in memory. It is not shaped in a ring but instead more like a tube.
